# Zeeshan Ansari — Portfolio

## Run locally

Install dependencies once, then start the Vite development server:

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Project structure

- `index.html` — Vite document and page metadata.
- `src/data/portfolio.js` — portfolio content.
- `src/components/` — reusable page sections and social links.
- `src/App.jsx` — page composition and shared interactions.
- `src/styles.css` — existing portfolio styles.
- `public/assets/portrait.webp` — optimized portrait used by modern browsers.
- `public/assets/portrait.jpg` — JPEG fallback for the portfolio portrait.
- `legacy.html` — preserved original standalone implementation.
